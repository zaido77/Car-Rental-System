# 🚗 Car Rental Management System

A desktop application developed in **C# (.NET Framework)** using **Windows Forms** and **SQL Server**, designed to streamline the daily operations of a car rental company.

This project was built as a comprehensive learning experience, applying layered architecture, object-oriented programming principles, and SQL database design to create a complete business management system.

---

## ✨ Features

### Authentication
- User login system.

### Customer Management
- Add, update, delete, and search customers.
- Customer profile images.

### Vehicle Management
- Manage vehicle information.
- Vehicle categories and availability.
- Mileage tracking.
- Vehicle search and filtering.

### Booking Management
- Create rental bookings.
- Select customer and vehicle.
- Rental period validation.
- Automatic rental cost calculation.

### Vehicle Returns
- Return rented vehicles.
- Calculate actual rental duration.
- Track consumed mileage.
- Additional charges.
- Final inspection notes.
- Automatic payment summary.

### Rental Transactions
- Automatic transaction generation.
- Remaining payment calculation.
- Refund calculation.
- Transaction history.

## 🏗 Architecture

The project follows a layered architecture to separate responsibilities and improve maintainability.

```
Presentation Layer
        │
        ▼
Business Layer
        │
        ▼
Data Access Layer
        │
        ▼
SQL Server Database
```
